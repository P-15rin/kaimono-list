この端末をリストにつなぐ

iPhone と PC で同じリストを見るために、リストの中身をあなたの GitHub アカウントの非公開メモ（Gist）に保存します。端末ごとに一度だけ、次の手順で「トークン」を入れてください。

  1. トークン作成ページを開く（GitHub にログインした状態で）
  2. 「Expiration」で有効期限を選ぶ（No expiration にすると更新の手間がありません）
  3. gist にだけチェックが入っていることを確認し、下の「Generate token」を押す
  4. 表示された ghp_ で始まる文字列をコピーして、下に貼り付ける

2台目の端末では、同じトークンを貼るか、同じ手順でもう1つ作ってください。トークンはこの端末の中にだけ保存され、メモ（Gist）の読み書き以外には使えません。
